# AI GO! Integrations

Welcome to the **LatticeFlow AI GO! Integrations** repository. 

<img width="1526" height="637" alt="image" src="https://github.com/user-attachments/assets/e42bde36-4dc1-4177-bb90-60bd8a018bcc" />

## Purpose

This repository serves as the central hub for learning how to connect your AI ecosystem
with the LatticeFlow AI GO! platform.

Whether you are benchmarking your AI system, connecting a custom RAG agent, or 
evaluating safety guardrails, this repository contains integration examples to 
seamlessly make your AI assets native to the AI GO!.


## Structure

The repository is modularly structured by different components in AI GO!. We use
**YAML** as the primary configuration language to define these components.

- [**AI Apps**](./apps)
  
  Explore examples of AI app definition - with minimal or extensive information 
  provided on the AI application's use case.

  **Example:** To create a new AI app:

  ```shell
  lf app create 'apps/minimal.yaml'
  ```

- [**Evaluations**](./evaluations)
  
  Explore examples of evaluation definition - that include a single or multiple
  task specifications with different configuration parameters. 

  **Example:** To run a new evaluation:

  ```shell
  lf evaluation run 'evaluations/airline_rag_performance.yaml'
  ```

- [**Tasks**](./tasks)

  Explore examples of (evaluation) task definition - with different solvers, scorers 
  and metrics.

  **Example:** To create a new task:

  ```shell
  lf task create 'tasks/singleturn_no_params_string_equals_simple_instructions.yaml'
  ```

- [**Models**](./models)

  Explore examples of model definition - with Bearer or custom authentication methods,
  with custom TLS/SSL certificate validation schemes, with models hosted by
  [OpenAI](https://platform.openai.com/docs/api-reference/introduction),
  [Dify](https://docs.dify.ai/en/use-dify/getting-started/introduction) and others.

  **Example:** To create a new model:

  ```shell
  lf model create 'models/model_openai_gpt-4.1-mini-2025-04-14.yaml'
  ```

- [**Model Adapters**](./model_adapters)

  Explore examples of model adapter definition - the identity (minimal) adapter,
  adapters for handling streaming and non-streaming model endpoints, adapters for models
  hosted by [OpenAI](https://platform.openai.com/docs/api-reference/introduction),
  [Dify](https://docs.dify.ai/en/use-dify/getting-started/introduction) and others.

  **Example:** To create a new model adapter:

  ```shell
  lf model-adapter create 'model_adapters/adapter_openai_chat_streaming.yaml'
  ```

- [**Datasets**](./datasets)

  Explore examples of dataset definition - with different data file formats, with data
  provided in a file or generated by the dataset generator.

  **Example:** To create a new dataset:
  
  ```shell
  lf dataset create 'datasets/jsonl_instructions_categorical_options.yaml'
  ```

- [**Dataset Generators**](./dataset_generators)

  Explore examples of dataset generator definition - with synthesizers, data sources and
  configuration parameters.

  **Example:** To create a new dataset generator:

  ```shell
  lf dataset-generator create 'dataset_generators/empty_source_questions.yaml'
  ```
